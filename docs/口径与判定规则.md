# abcheck 统计口径与判定规则（v1.1）

本文件是后端 `backend/src/utils/statistics.py` + `backend/src/services/analysis_service.py`
的唯一口径说明。所有数字由后端计算并落库，前端只展示。

> v1.1 变更：分析引擎从「恰好 2 个变体」扩展为「1 个共同对照 + k 个处理方案」。
> 两臂实验的计算与落库结构完全不变；多臂（>2 变体）实验逐方案对账、全部检验
> 合并进同一个 BH family 做误报控制，并为每个方案给出 verdict 与可上线状态
> `ship_state`（ship_eligible / watch_only / blocked）。

## 1. 样本口径

| 校验 | 抽样单元 | 说明 |
|---|---|---|
| SRM 分流校验 | **曝光次数**（`assignments.exposure_count` 累计） | 曝光级实验：同一用户窗口内多次进入页面重复计数 |
| 比例指标 | **用户**（一条分桶记录 = 1 用户） | `x = Σ flags[metric_code]`，`n = 用户数` |
| 均值指标 | **用户** | `metric_value` 为用户级指标值 |

> 为什么 SRM 用曝光口径：埋点重复上报/自动刷新会让「曝光次数」先失衡，
> 曝光级 SRM 能在用户级指标被污染前发现异常；seed 中实验 A 即为此类。

## 2. SRM（分流比例失衡）

```
观测 O_i = 各变体曝光次数
期望 E_i = 总曝光 × 流量配比（归一化）
χ² = Σ (O_i − E_i)² / E_i , df = k − 1
p  = P(χ²_df > χ²)
```

- 阈值：实验级 `srm_threshold`（默认 `0.001`）；
- `p < 阈值` → `verdict=detected`，整体结论 `unreadable` 且 `locked=true`，
  **指标 p 值一律不可采信**，决策接口返回 423；
- 总曝光 < `min_srm_exposures`（500）→ `verdict=insufficient` → `unreadable`；
- **多臂实验两档校验**：先对全部变体做一次全实验 SRM（df=k−1）；再对
  「共同对照 vs 每个处理方案」做配对 SRM（按两个变体的流量配比归一化，df=1），
  配对 SRM 失衡只锁定该方案，其余方案仍可读。

seed 事实：实验 A 观测 47.705% / 52.295%（3118 / 3418 次，共 6536），
χ²=13.7699，df=1，p=0.0002066 < 0.001 → SRM。

## 3. 比例指标：两比例 z 检验（合并方差）

```
p_c = x_c/n_c , p_t = x_t/n_t , p̄ = (x_c+x_t)/(n_c+n_t)
z = (p_t − p_c) / sqrt( p̄(1−p̄)(1/n_c + 1/n_t) )
p_value = 2·(1 − Φ(|z|))
```

- 效应量：`diff = p_t − p_c`，`lift = diff / p_c`；
- `lift_ci95`：`diff ± z_{1−α/2} · sqrt(p_c(1−p_c)/n_c + p_t(1−p_t)/n_t)`，再同除 `p_c`；
- `mde_required.absolute = (z_{1−α/2}+z_{0.8})·sqrt(p_c(1−p_c)(1/n_c+1/n_t))`，`relative = absolute/p_c`。

## 4. 均值指标：Welch t 检验

```
diff = m_t − m_c , se = sqrt(s_c²/n_c + s_t²/n_t)
t = diff/se
df = (s_c²/n_c + s_t²/n_t)² / [ (s_c²/n_c)²/(n_c−1) + (s_t²/n_t)²/(n_t−1) ]
p_value = 2·P(T_df > |t|)
lift_ci95 = (diff ± t_{1−α/2,df}·se) / m_c
mde_required.absolute = (z_{1−α/2}+z_{0.8})·se
```

seed 事实：实验 B 主指标 `arpu`，对照均值 185.00、实验均值 192.74，
lift=+4.19%，Welch t=2.1574，df≈1397.9，p=0.0311，lift CI≈[+0.38%, +7.99%]，
MDE(80%)=5.44%（观测效应略低于 MDE，结论落在功效边界）。

## 5. 多重比较：Benjamini–Hochberg FDR

输入 m 个 p 值，升序排名 k=1..m：

```
q_(k) = min_{j ≥ k} ( p_(j) · m / j )
```

- **分层内**：每个处理方案的 6 个分层（城市 3 × 新老客 2）各做一次主指标检验 → 该方案一个 BH family；
- **守卫族**：每个处理方案的守卫指标单独一个 family；
- **全量**：主指标 + 守卫 + 辅助 + 全部分层合并一个 family，写入批次的 `comparisons`。
  - 两臂实验：与历史口径完全一致（单一处理方案的全部检验）；
  - **多臂实验：跨全部处理方案合并成同一个 family**（m = 方案数 × 每方案检验数），
    保证「所有方案的比较放进同一套误报控制」。

seed 事实（实验 B 分层）：
原始 p = [0.0136, 0.0397, 0.6237, 0.9187, 0.9534, 0.8535]，
BH 后 q = [0.0814, 0.1191, 0.9534, 0.9534, 0.9534, 0.9534]：
2 个分层「原始显著但校正后不显著」→ warn 的主要依据。

seed 事实（实验 E 三臂，全量 family m=20）：
短文案主指标 p=0.00053 → 全方案 BH q=0.0106（仍显著，ship_eligible）；
领券文案主指标 p=0.02256（原始显著）→ 全方案 BH q=0.1504（校正后失真），
且客诉率守卫族 q=0.0048 显著变差 → 该方案 fail / blocked。

## 5a. 多臂实验：共同对照与可上线状态

- **共同对照**：全部处理方案与同一个对照臂比较；用户级指标各自独立检验，
  对照臂样本在各方案间复用（展示与报告逐方案标注 `control_variant`）；
- **配对 SRM**：每个处理方案单独与对照臂做一次曝光口径卡方（df=1）；
- **统一误报控制**：所有方案的主/守卫/辅助/分层检验并入同一个 BH family；
- 每个方案输出四档 `verdict` 与三档 `ship_state`：

| ship_state | 含义 | 对应 verdict |
| --- | --- | --- |
| `ship_eligible` | 可上线：全方案 BH 后仍显著且守卫无回归，可作为赢家 | pass |
| `watch_only` | 仅可继续观察/带风险评审（分层异质、反向显著或功效边界） | warn |
| `blocked` | 禁止上线：守卫生效、校正后失真、SRM/样本不足或主指标不显著 | fail / unreadable |

**守卫生效或全方案 BH 校正后失真的方案一律 `blocked`，不能被当成赢家。**
批次总判定取方案级最优档（有 pass 则 pass，否则有 warn 则 warn，否则 fail）；
SRM 全实验锁定时总判定与全部方案均为 unreadable。

## 6. 守卫指标回归

按指标 `direction` 判断方向：`decrease_good` 显著上升 = 变差；`increase_good` 显著下降 = 变差。
显著 = 守卫族内 BH 后 `q ≤ α`。任一守卫显著变差 → 结论 `fail`。

## 7. 结论固定规则（按顺序短路，逐方案执行）

1. SRM `detected` / `insufficient`（全实验或该方案配对 SRM）→ `unreadable`（`locked=true`）；
2. 每臂样本 < `min_sample_per_arm` → `unreadable`；
3. 任一守卫指标显著变差（守卫族内 BH）→ `fail`；多臂时若主指标同时在全方案 BH 后失真，
   理由中并列两条事实；
4. 主指标 `p ≥ α` → `fail`；
5. **多臂专属**：主指标原始 `p < α` 但全方案统一 BH 后 `q > α`（校正后失真）→ `fail`；
   两臂实验不做该校验（单一预注册主指标，沿用原口径）；
6. 任一：
   - ≥2 个分层原始显著但 BH 后不显著（异质性/挑选显著），
   - 存在方向相反的分层显著项，
   - 观测 |lift| < MDE（功效边界）
   → `warn`；
7. 其余 → `pass`。

## 8. 可复现性

- seed 分桶数据由固定 `random.Random(seed)` 生成后**按目标均值/标准差标准化**，
  落库前四舍五入到 6 位小数（`DECIMAL(14,6)`），同一 seed 在任意机器得到同一组 p 值；
- 统计函数只用标准库 `math`（`erf` / 正则不完全 Gamma / 正则不完全 Beta），无版本漂移；
- 批次结果整体落 `analysis_runs`（JSON 列），多臂逐方案结果落新增的 `arms` JSON 列
  （迁移 0002_multi_arm，旧两臂批次该列为空，老结构字段保持不变），报告直接从库中渲染。
